# Đầu ra Mộc Studio — S10 / MOC-WIN-1

Hai file HTML/CSS do Codex tạo trong phiên triển khai S10, theo brief của bài học.
Mộc Studio là dịch vụ hư cấu; nội dung và hình khối CSS là minh họa gốc.
Không có ảnh/font ngoài, form, JavaScript, package, API, thu thập dữ liệu hoặc đặt lịch.

Mở index.html trực tiếp bằng trình duyệt trên Windows. Không cần npm/server.
Bản phục vụ trong theme: themes/vibelab/assets/moc-studio. Test S10 đối chiếu byte/hash
hai bản trước khi nghiệm thu. Khi sửa mẫu phải cập nhật cả hai và chạy lại test:lesson.

Lệnh bài học và brief: docs/content-samples/S10-moc-studio-lesson.html.
Hợp đồng: docs/S10-lesson-contract.vi.md. Bằng chứng: docs/acceptance/S10.

Kiểm thử tự động replay đầu ra này trong thư mục mới trên máy đã có công cụ:
Windows PowerShell5.1 và PowerShell7.6.5, file local thật, liên kết/CTA/mobile,
sửa tiêu đề và khôi phục. Không gọi lại AI trả phí hoặc chứng nhận đã thử cài mới/
đăng nhập Codex. Không bảo đảm mỗi lần agent tạo mã giống ví dụ này.
