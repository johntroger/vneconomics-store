# Thư mục làm việc của Claude Code

Mọi nội dung do Claude Code (phiên cloud) tạo ra nằm trong thư mục này, tách khỏi phần Codex đang làm, để tránh xung đột.

- Claude Code chỉ tạo hoặc sửa file trong `claude-code/`. Không đụng code, theme, plugin, importer, `AGENTS.md`, `docs/`.
- Mọi thứ ở đây là bản nháp, chưa import, chưa xuất bản. Phát hành vẫn theo pipeline gated của chủ site/Codex.
- Đổi tên hoặc chuyển bản nháp sang `docs/content-production/` là việc của chủ site hoặc Codex, không phải của Claude Code.
