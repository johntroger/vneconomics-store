# Candidate key observer — profile chỉ đọc

Profile mới `vibelab-v2-r6-css-production-key-observe-schema3` dùng package sáu file, source/controller/payload/manifest/receiver pin riêng và baseline R6. Application ZIP giữ cùng bytes với inspection/runtime builder; manifest `deployAuthorized:false`. Capability chỉ gồm inspect inbox/context/storage và `observe-key-candidate`; không có `css-runtime` hoặc import/write/activation key.

[Builder](../scripts/release-r6-css-adapter.mjs) cung cấp `prepareProductionKeyObservationAdapter`. [Operator entry](../scripts/r6-css-key-observer.mjs) cung cấp `buildProductionKeyObservationBootstrap(approval,request)`. Approval là schema inspection-context đóng: environment production, profile mới, sáu pins và contextPhase baseline/candidate. Request là candidate-possession protocol hiện có, với operationId/kind/target/expected-active/candidate fingerprint/challenge/TTL tối đa60 giây. Không nhận key, path, PHP hoặc override transport. Builder chỉ tạo command CLI `--user=1`, không thực thi.

Bootstrap kiểm loaded WordPress/canonical root/inbox và hash controller/manifest trước include. [Dispatcher](../release-tools/r6-css-adapter.php) kiểm schema/token/request, toàn package/ref, đúng profile và loaded WordPress context trước khi gọi observer. Helper đọc descriptor của active/candidate key, kiểm UID10044/GID1004, directory0700/file0600, nlink/identity và đối chiếu lại sau đọc. Initial yêu cầu chưa có active key; rotation yêu cầu active fingerprint khớp. Không tạo folder/key/mutex/journal/lock hoặc đổi active key. Package runtime cũ không có quyền observation; package observation không có quyền runtime install.

Kết quả chỉ chứa status và HMAC possession proof. Các cờ `keyReturned`, `serverOriginVerified`, `writerReservationVerified`, `activationAuthorized`, `provisioningAuthorized` giữ false. Proof hợp lệ chỉ chứng minh đang giữ candidate bytes phù hợp; local cũng giữ shared key nên HMAC không tự xác minh nguồn server hoặc reservation. Gate vận hành còn phải đối chiếu browser/session/đích/command provenance và đường truyền file candidate riêng tư.

Kiểm local qua `npm run test:css-dispatcher-native`: tái sử dụng WordPress/MariaDB/container hiện có, hai package synthetic trong cùng fixture. Helper fixture đổi package/ref và seed candidate chỉ trong container được sentinel bảo vệ; production observer không seed hoặc nhận raw key. Test kiểm missing candidate/no-create, pin/profile/capability/context refusal, initial/rotation HMAC với Node verifier, bad mode/fingerprint, private metadata/bytes và protected MariaDB baseline không đổi. Sau đó chạy nguyên11 nhóm runtime/recovery trên package runtime. Không dùng đổi package fixture như đường triển khai thực.

Chỉ kết quả CI đúng source SHA và đủ17 nhóm chứng nhận phần observer/runtime này; kết quả11 nhóm của source cũ không bao gồm observer. Chưa tạo key thật, upload browser hoặc cài trên Plesk. Ba plugin bên thứ ba vẫn metadata stub và HTTP health synthetic. Khả năng command chạy trong WP Toolkit/maintenance, nguồn observation, transport/reservation/activation và coordinator production qua restart còn ngoài chứng nhận.
