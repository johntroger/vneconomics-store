Việc nào đáng dùng để tìm hiểu?

Một API công khai chỉ đọc, quan sát mã trạng thái và cấu trúc phản hồi. Đây là tình huống biên tập đề xuất, chưa phải kết quả đã chạy thử.

Điều kiện trước khi bắt đầu

Lối bắt đầu cho người mới

  1. Mở Documentation từ README và tìm phần gửi yêu cầu HTTP cơ bản.
  2. Dùng endpoint công khai được phép với GET, ghi URL, mã trạng thái và các trường phản hồi.
  3. Chưa thêm token hoặc đổi sang POST/DELETE cho đến khi hiểu tác động và quyền của API đích.
